# Guarding Multi-Agent Interactions

A framework for analyzing and monitoring cooperative multi-agent systems with error detection and intervention mechanisms.

## Overview

This project implements tools for running multi-agent simulations, detecting errors in agent interactions, and visualizing complex multi-agent behaviors through Dynamic Interaction Graphs (DIG).

## Installation

```bash
conda env create -f environment.yml
conda activate guarding-multi-agent-interactions
```

## Core Components

### Dynamic Interaction Graph (DIG)
`general_agents/core/dig.py`

Tracks all multi-agent interactions including events generated by agents, activations when agents process events, message flow between agents, and completion signals.

### MultiAgentEnvironment
`general_agents/core/environment.py`

Orchestrates the execution of multi-agent systems, managing agent lifecycles and coordinating interactions.

### Error Detection
`general_agents/analysis/error_detection/`

- **`llm_judge.py`**: Uses language models to identify errors in agent interactions
- **`error_detection.py`**: Rule-based error detection methods
- **`intervention.py`**: Mechanisms for intervening when errors are detected

### Visualization
`general_agents/viz/`

- **`viz_interactive.py`**: Generates interactive HTML visualizations of interaction graphs
- **`viz_realtime.py`**: Provides real-time visualization during execution

## How to Run

### Quick Test

```bash
cd count_freq
python quick_test.py
```

### Count Frequency Experiments

```bash
cd count_freq

# Single run with LLM judge
python run_llm_judge.py

# Run multiple experiments
python run_experiments.py

# Grid search over parameters
python run_grid_experiments.py

# Plot results
python plot_grid_results.py
```

### Newsgroup Frequency Experiments

```bash
cd newsgroup_freq
python run_experiments.py
```

## Experiment Outputs

Each experiment run generates:
- `run_meta.json` - Metadata about the run (agents, timing, configuration)
- `changelog.json` - Detailed log of all events and activations
- `interactive_viz.html` - Interactive visualization of agent interactions
- `realtime_viz_final.png` - Final visualization snapshot
