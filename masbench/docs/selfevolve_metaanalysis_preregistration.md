# Meta-Analysis Pre-Registration — gen vs select / best-fixed (Silo-Bench)

**Registered 2026-06-13, BEFORE any draw is run. Frozen at commit `575e6093` (M27/M28 both default-off).**

This is a **confirmatory final test, not a method-iteration round.** No method code
changes. The question is purely statistical: gen self-evolution has a real but
single-window-noisy edge over the strongest baselines (pilot: vs fixed +10.86pp,
vs select +5.05pp; single-window SD ~20pp). A pre-registered meta-analysis over
N independent draws cuts that noise by √N and asks whether the pooled effect is
significant. Locking N + seeds + decision rule *before* running is what makes the
result admissible — running-until-significant (optional stopping) would be p-hacking.

## Hypotheses (one-sided)

- **H1 (co-primary):** pooled draw-level paired mean (gen − `fixed_best_on_train`) > 0.
- **H2 (co-primary):** pooled draw-level paired mean (gen − `select`) > 0.
- **Secondary (non-gating):** gen − `coldgen` (already robust, sanity); gen − full `refine` (reported only).

## Power analysis (fixes N)

Pilot = 11 historical draws (`scripts/plot_gen_aggregate.py` DRAWS). Draw-level
effect sizes: **fixed d=0.54 → N≈22**; **select d=0.40 → N≈39** for 80% power,
one-sided α=0.05 (z-method `((1.645+0.842)/d)²`). We take **N=39** so BOTH co-primary
arms reach ~80% power. *Limitation (honest):* d is estimated from a mixed-judge
pilot; if the true unified-judge d is smaller, realized power is lower. This is an
inherent property of pilot-based power analysis, not a deviation.

## Fixed design (locked)

- **Code:** frozen `575e6093`. No source edits while drawing (red line).
- **Judge:** `scripts/verify_beats_baselines.py`, 4-arm, `--evolved-mode graph_generate`.
  Unified baseline = `fixed_best_on_train` for ALL draws (pilot's `sup`-judge
  `oracle_fixed` is a *different, stronger* definition → pilot draws are NOT pooled
  into the meta; they served only to estimate d).
- **Cases / split (fixed):** pool `I-01 I-02 I-04 I-06 I-07 I-08 II-13 II-15 II-17 II-19`,
  `--holdout-frac 0.3` → deterministic `_split_cases` → **TRAIN={I-01,02,04,06,07,08,II-13}**,
  **TEST={II-15,II-17,II-19}**. Fixed split controls case-difficulty confound so
  between-draw variance is pure random replication (what the meta needs).
- **Draws:** **39 draws × 8 eval-seeds**, generated by `random.Random(20260613)`,
  all 312 seeds disjoint, range [10000,99999]. Locked in `runs/p3_meta_draws.json`.
  Each draw = 3 test cases × 8 seeds = **24 paired runs**.
- **Protocol constants:** `--rounds 5 --n-agents 5 --train-seeds 1 2 --val-seeds 3`,
  default `--fixed-topologies`, `--workers 8`.
- **Cache hygiene:** every draw runs in its own dir with FRESH EMPTY caches. No
  cross-draw cache seeding (M19d).

## Aggregation method (locked)

1. Per draw: `delta_arm = mean over its 24 pairs of (gen − arm)`, for arm ∈ {fixed, select, coldgen}.
2. Across the 39 draws: one-sample one-sided t-test, H0: delta ≤ 0, **draw-weighted**
   (each draw = 1 vote), α=0.05. Report pooled mean, 95% CI, t, df=38, p.
3. The 39-draw forest plot regenerates via an extended `plot_gen_aggregate.py`.

## Decision rule (locked, applied ONLY after all 39 complete)

- H1 p<0.05 → **"robust pooled dominance over the strongest fixed topology."**
- H2 p<0.05 → **"robust pooled dominance over select."**
- Either arm n.s. → **"effect real but N=39 insufficient for pooled significance"** —
  recorded as the honest boundary (legitimate per the "该规模下检测不到稳定效果是合法结论" rule).
- **NO optional stopping / NO peeking-then-stopping.** Analysis is unblinded only
  after all 39 draws finish. All 39 enter the analysis (no draw dropped for being low).

## Bias controls

- No draw is cherry-picked or excluded by outcome; the locked seed list is exhaustive.
- A draw that dies on infra error (API/network) is **re-run with the SAME seeds**
  (deterministic re-run, never a re-roll to new seeds) and logged.
- No method-code edits during the run; pilot draws excluded from the pooled estimate.
