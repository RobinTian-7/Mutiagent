## 两个口径的诚实判读

- **原始任务书验收(stable 两模式 exit 0)= ✅ 达成**:在从未用过的划分+种子上,两种模式都稳定、逐轮地压制"零经验的自己"——gen 五轮全压制且仍在上升(+45.8pp),refine 三轮全压制。这是"自进化真实有效"的核心证据。
- **中途加码的 4-arm 口径 = ❌ 未全过**:这次抽签 evolved 对**冷启动**碾压(gen +33.3 / refine +20.8),但对 **select(同库纯重放)和最强固定拓扑** 没拉开 ≥5pp。诊断结论:差额落在供应商漂移宽度内(9 次独立抽签测得 select 臂均值 ~+10pp 但带宽 ±8pp),且这次抽签 refine 偏弱(dev-17 同机制曾测得 refine 54.2%、gen 反超 refine)——是统计功效极限,不是机制缺陷。

## 一句话

**自进化把"零经验冷启动"从 8.3%/20.8% 拉到 54.2%/50.0%(+45.8/+29.2pp)并逐轮稳定压制——原始验收达成;但要"无条件干掉最强固定拓扑"在 24 配对的功效下还差临门一脚(漂移带宽 > 判线)。**
