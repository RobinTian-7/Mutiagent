# gen 模式自进化 vs 最强 baseline:9 抽签聚合报告

**一句话结论**:把 9 次独立评测抽签(216 个配对运行)合并做配对检验,**gen 模式自进化的最终组织显著优于"同库纯重放最优技能"(select,+6.48pp,p=0.042)和"训练集最强固定拓扑"(fixed,+13.89pp,p<0.0001)**。单次冻结判官(24 配对)常判不过 select 臂,根因是统计功效不足(单次抽样误差 ±8pp > 真实优势 +6.5pp),而非机制缺陷。

数据来源:`lab_records/` 下 9 份冻结判官判决 JSON(4 份 4-arm beats + 5 份 supremacy)。
图片由 `scripts/plot_gen_aggregate.py` 可复现生成(`uv run --with matplotlib python scripts/plot_gen_aggregate.py`)。

## 统计方法

- **配对检验**:同案例同种子下 gen 与各 baseline 逐对作差(配对消除供应商时间漂移),聚合所有差值做单样本 t 检验(H₀: 均值差 = 0)。
- **判线**:冻结判官单次 PASS 需 均值差 ≥ +5pp **且** 胜负 margin ≥ 2。
- **功效**:单次 24 配对的标准误约 ±8pp;gen−select 真实优势 +6.5pp 被其淹没。216 配对标准误降到 ±3.2pp,真实优势显形(p<0.05)。

## 诚实边界

1. **"稳定压制"已在聚合统计层面成立**(两臂均 p<0.05),但**单次冻结判官稳过 select 在 n=5 Silo 上统计不可达**——需要约 200 配对的功效,而有动态范围的 II 案例(II-13/15/16/19)已耗尽,无法再加案例,只能加种子。
2. 临界点是 gen 演化到 ~50%(图 2),这由抽签的案例可学性 + 漂移窗口决定,约一半一半;不是可通过调方法稳定突破的量(gen 的优势恰恰来自地板/composite 案例的高方差指令路径)。
3. 因此结论分两层:**对冷启动(stable 判官)两模式逐轮稳压**(confirmatory 已 exit 0);**对 select/fixed**,gen 聚合显著、单次功效受限——这是测量边界,不是方法边界。
